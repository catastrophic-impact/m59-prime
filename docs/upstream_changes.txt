UPSTREAM (pinned, never edited in place: our work = patches + overlay applied on top; see prime_server/UPSTREAM.txt for the exact commits):

HOW TO TAKE AN UPSTREAM UPDATE: change the pin in prime_server/UPSTREAM.txt, rebuild with prime_server/scripts/prepare_tree.sh (applies the patches in order), fix the patches that no longer apply (docs/BUILDING.md), then run the tests (docs/TESTING.md, claude_tools/walkcheck.py).
