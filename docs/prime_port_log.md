# Class-system port onto the Prime server (Server 104 base): progress log
Method: our logic lives in overlay files (prime_server/overlay/kod/object/prime/), upstream files get one-line hooks (prime_server/patches/). Build: prime_server/scripts/build.sh --quick (clean kod rebuild, ~3 min); test server: run_test_server.sh / stop_test_server.sh; admin: scripts/admin_prime.py.
Gotchas: Send(&Class,...) is a broadcast to instances, not a static call: our singleton is System.GetPrime (patch 0003). An incremental kod build corrupts class ids: always build clean. Never `pkill -f` (kills the tool shell).
