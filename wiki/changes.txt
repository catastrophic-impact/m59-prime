MERIDIAN 59 PRIME - EVERYTHING THAT DIFFERS FROM THE ORIGINAL REPOS
===================================================================
Written 2026-10-22. Prime is built from two pinned upstream projects plus our own patches and files:
  server  jboullion/shards-server       pinned at a9960bf1  (Server 104 code, 64-bit Linux build)
  client  jboullion/meridian-shards     pinned at e631c9e   (TypeScript/Vite/React web client)
Everything below is OURS. "Patch" = a numbered diff applied on top of the pinned upstream (prime_server/patches, prime_client/patches).
"Overlay" = whole new files we add (prime_server/overlay, prime_client/overlay).
STATUS tags: [tested] checked in the running game or by admin calls, [built] compiles and loads but not played, [untested] written but not run.

3. THE CLASS SYSTEM (what the code now says)
--------------------------------------------------------------------
Classes (primeclasses.kod): Warrior 1, Monk 2 (the old Priest), Paladin 3, Elementalist 4, Priest 5 (reserved, not playable).
God of the class: Warrior = Kraanan, Monk and Paladin = Shal'ille, Elementalist = Faren.
Stats (might/stamina/agility/intellect/mysticism/aim), not shown at character creation:
  Warrior 50/50/50/1/1/50   Monk 50/30/50/50/50/30   Paladin 50/40/30/30/30/30   Elementalist 30/30/20/50/50/1
Start: Warrior and Paladin a mace, Monk and Elementalist a light robe; 500 shillings; reagents for the level-1 spells; every class also starts with Sweep.
  (Conveyance and Transference were asked for but are retired upstream: they are buttons in the client now, not spells.)
Ability tables (full list and gear in wiki/classes_and_gear.txt):
  Warrior: L1 Slash, Glow, Block / L2 Fencing, Second Wind, Dodge / L3 Hammer, Super Strength, Parry / L4 Axe, Bless, Magic Shield / L5 Scimitar, Free Action, Disarm /
           L6 Armor of Gort, Resist Magic, Deflect, Anti-Magic Aura
  Monk: L1 Punch, Minor Heal, Mana Focus / L2 Holy Touch, Brawling, Dodge / L3 Bless, Hospice, Block / L4 Holy Blaze, Dazzle, Magic Shield / L5 Night Vision, Major Heal, Rescue / L6 Purify, Truce, Purge
  Paladin: L1 Slash, Minor Heal, Block / L2 Fencing, Spiritual Sword, Dodge / L3 Bless, Hospice, Forces of Light / L4 Hammer, Spiritual Hammer, Magic Shield / L5 Super Strength, Glow, Parry / L6 Purify, Major Heal, Armor of Gort
  Elementalist: L1 Touch of Flame, Minor Heal, Mana Focus / L2 Illuminate, Icy Fingers, Dodge / L3 Fireball, Ice Shard, Mana Shield / L4 Winds, Mystic Touch, Magic Shield / L5 Ice Nova, Firewall, Explosive Frost
Weapons AND armor: every class may use anything (untrained weapons do only their base damage). The class armor limits were REMOVED on 2026-10-22 (the ItemLevel/ClassArmorLevel
  tables stay in the code for the planned trade-offs: heavier armor costs dodge for dodge classes (monk, later rogue) and spell power; numbers still to be decided).
  Gear levels: robe 1, leather 2, chain 3, scale 4, nerudite 5, plate 6; helmets and shields mapped by their own numbers.
Level rules: level 1 is free, the next level opens when the best three abilities of the previous level reach the usual threshold (Intellect still helps).
Threat: warrior 5 per hit, paladin 3.  Second Wind: warrior-only out-of-combat heal.  Paladin/Monk robes show their class level.

4. OTHER SERVER BEHAVIOUR CHANGES
--------------------------------------------------------------------
- Karma on players is gone (GetKarma = 0 in the base): nothing is blocked by karma.  Holy Touch no longer scales with a monster's karma.
- Rules switchable live (Rules tab of the admin TUI / prime_set.sh): death item drop and stat loss, reagent mode (mandatory / not needed / optional=weaker), unlimited eating,
  bow shots without arrows, dagger double-hit chance.
- Groups: up to 5 including companions, invitations expire after 60 s, 1 s tick pushes the state to the client.
- Companions: a "warrior companion" can be called any time; it follows the owner's effective level and shares kills (XP goes to the owner).
- Vigor: the rest cap is 100 for everyone.
- Weapons: Mace unchanged (a try to buff it was reverted).  Dagger: "dagger" name and 25% double hit.
- Free spells: nothing else added.  Conveyance/Transference stay as client buttons.

8. ADMIN HOWTO (2026-10-22)
--------------------------------------------------------------------
- Admin tools live in the terminal admin (Accounts and Characters tabs) and in the game (admin console).
- Make an admin: TUI Accounts tab -> Create (type admin, a password, any name) -> select the account -> "Make an admin character" -> log in with that account in the client and
  create/pick the character (it may have a class). An account's type cannot be changed later; make a new admin account instead (no restart needed).
- In the game, open the admin console from the menu (the three-bar menu at the top left, "Admin console...").  Tabs: Travel (every room), Players (go to, bring here, rescue, tell),
  Self (items, money, powers), World, Prime (class level, health, shillings, items, disciple robes for yourself or the player picked on the Players tab).
- After EVERY server rebuild run prime_client/scripts/run_dev.sh: it syncs the client's strings; without it new server messages show wrong text.
